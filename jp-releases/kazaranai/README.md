# 飾らない版 (v13_light) — バッジとれーるセンター JP オフラインパッチ

code.ips SHA-256: `5cc924659a79c1a85212277f4cd2fee59237edad938c222b449c31d74173d2b7`
(2,793 bytes / 53 records / 43 hooks)

HOME メニュー側のバッジデータに**書き込まない**版。v13 (飾れる版) との
差分は badge_home_* スタブ 9 件のみ: 書き出しワーカーは起動されず、
HOME 連携の照会は「バッジなし」を返す。それ以外の 6 件 (共有 extdata
0x14D1 の生成チェーン、説明フラグ、起動直後の回復処理) は起動に必須の
ためネイティブのまま。

## できること

- オフラインで起動・タイトル到達 (Azahar でフレッシュ起動を含む
  2 回起動を検証済み: SD エラー状態にならない)
- 練習キャッチャー / 通常台、0 円購入、バッジのゲーム内保存・復元、
  初回説明の永続化、プレイ中の HOME ボタン
  (ゲーム側の挙動は v13 と同一構成で、v13 で実機確認済み)

## 既知の制限

- **実機は未検証**。初回は起動チェックをお願いしたい: 起動して
  タイトルまで進めば OK。万一、初回起動で SD エラー
  (「SDカードが読み取れませんでした」) が出たら「飾れる版」を使うこと。
- HOME メニューの「バッジをかざる」は使えない (バッジが認識できない
  旨の表示になる)。ゲーム内コレクションの閲覧は可能。
- 共有 extdata 0x14D1 自体は起動に必要なため自動生成されるが、
  中身 (BadgeMngFile.dat / BadgeData.dat) は初期状態のまま
  書き換えられない。

3. Luma の game patching を有効にして起動する。
