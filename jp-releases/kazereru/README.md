# 飾れる版 (v13) — バッジとれーるセンター JP オフラインパッチ

code.ips SHA-256: `369bca8094f76894d1db37acb8c402338f441d1353f49343b8f9178ff6bbca4d`
(2,712 bytes / 44 records / 34 hooks)

HOME メニュー連携 (バッジ書き出し) を含むフル版。badge_home_* スタブは
全て外してあり、共有バッジ extdata (0x14D1) の生成・HOME への書き出しは
ネイティブのまま動く。

## できること (実機確認済み)

- オフラインで起動・タイトル到達 (SD エラーなし)
- 練習キャッチャー / 通常台が遊べる、無料プレイなしでも 0 円購入で継続可
- 獲ったバッジの保存と、再起動後のプロフィール/ステージ復元
- 初回説明 (チュートリアル) がカテゴリごとに永続化され、2 回目以降は出ない
- プレイ中の HOME ボタンが使える

## 既知の制限

- **「バッジをかざる」自体は未検証**: 書き出し経路はネイティブで有効に
  なっているが、実際に飾れるかの実機確認はまだ。バッジを 1 つ獲って
  HOME メニューの「バッジをかざる」を試してほしい。
- この版は HOME メニュー側のバッジデータをゲーム内コレクションから
  書き換える。GYTB 等で入れた既存の HOME バッジがある場合、それが
  置き換わる可能性がある (今の本体には HOME バッジデータは無いので
  初回は影響なし)。元に戻したい場合は「飾らない版」を使うこと
  (ただし書き換え済みデータは戻らない)。

## 導入

1. 更新タイトル `0004000e00134600` がインストール済みであること。
2. この `code.ips` を SD の `luma/titles/0004000000134600/` に置く。
3. Luma の game patching を有効にして起動する。
   ※ 初回起動時に extdata 0x14D1 が自動生成される (正常動作)。
